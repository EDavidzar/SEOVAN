# SEOVAN
PROGRAMA DE AYUDA PARA EL ANÁLISIS, DESCRIPCIÓN Y EVALUACIÓN DE FUENTES DE INFORMACIÓN ESPECIALIZADAS

Programa basado en el sistema de análisis, identificación y descripción de fuentes especializadas del profesor Blazquez Ochando
Fuentes de información en Humanidades, Ciencias Sociales, Ciencia y Tecnología
BLÁZQUEZ OCHANDO, M. 2015
Prof. Manuel Blázquez Ochando
Dpto. Biblioteconomía y Documentación
Universidad Complutense de Madrid
manublaz@ucm.es mblazquez.es

https://ccdoc-fuentesespecializadas.blogspot.com/2015/03/06-descripcion-y-evaluacion-de-fuentes.html

El programa ayuda al análisis, identificación y descripción y evaluación de fuentes de información especializadas, con el mismo se introducen los datos de la fuente de información y su evaluación en una base de datos para su posterior consulta y utilización.
Se utiliza un servidor de base de datos MYSQL/MARIADB en los que se introducen los datos de una o varias fuentes de información y su evaluación según los criterios del Profesor Manuel Blázquez Ochando para su búsqueda y consulta.

Ha sido desarrollado en el lenguaje de programación Java y se puede ejecutar en cualquier sistema/entorno operativo en el que se pueda instalar, esté instalado y configurado  Java Runtime Environment (JRE). versión mínima 17.0 de Java Runtime Environment (JRE).

Using Program /WebPage/PrincipalWindowTopComponent.html.



# SEOVAN
SOFTWARE PROGRAM FOR THE ANALYSIS, DESCRIPTION, AND EVALUATION OF SPECIALIZED INFORMATION SOURCES

A program based on Professor Blázquez Ochando’s system for the analysis, identification, and description of specialized sources
Information sources in the Humanities, Social Sciences, Science, and Technology
BLÁZQUEZ OCHANDO, M. 2015
Prof. Manuel Blázquez Ochando
Department of Library Science and Documentation
Complutense University of Madrid
manublaz@ucm.es mblazquez.es

https://ccdoc-fuentesespecializadas.blogspot.com/2015/03/06-descripcion-y-evaluacion-de-fuentes.html

The program assists in the analysis, identification, description, and evaluation of specialized information sources. With it, data from the information source and its evaluation are entered into a database for later consultation and use.
A MYSQL/MARIADB database server is used to enter data from one or more information sources and their evaluation according to the criteria established by Professor Manuel Blázquez Ochando for searching and consultation.

It has been developed in the Java programming language and can run on any operating system or environment where the Java Runtime Environment (JRE) can be installed, is installed, and is configured. Minimum version 17.0 of the Java Runtime Environment (JRE) is required.
