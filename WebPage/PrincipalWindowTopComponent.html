La forma de actuación es la siguiente:

Para introducir o actualizar los datos se selecciona el panel adecuado, ya sea de análisis o evaluación, se introducen o actualizan los datos y se pulsa el botón de crear o actualizar registro.Se debe empezar siempre por el panel de análisis.

Para borrar los datos se selecciona el registro a borrar y se pulsa el botón de borrar registro
